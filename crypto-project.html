🔐 Caesar Cipher

Shifts each letter by a fixed number. Simple but foundational — ROT13 is a special case with shift of 13.

⚡ XOR Cipher

XORs each character with a key. Symmetric — the same operation encrypts and decrypts. Used in real crypto.

🔑 Vigenère Cipher

Polyalphabetic substitution using a keyword. Much stronger than Caesar — different shift for each character.
